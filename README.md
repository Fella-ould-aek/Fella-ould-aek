## Projects

###  Event-Driven Autoscaling with KEDA — Final Year Project (PFE)
CPU-based autoscaling is blind to queue depth. A consumer pod waiting for its next message consumes no CPU, so HPA never scales it, no matter how large the backlog grows. I implemented KEDA to scale directly on RabbitMQ queue depth, validated it across three load scenarios, and proved it handles what HPA architecturally cannot.

🔗 [View Repository](https://github.com/Fella-ould-aek)

---

### ⚙️ Self-Managed Kubernetes Cluster,  Full DevOps Pipeline
Managed Kubernetes hides what's actually running your infrastructure. I built a self-managed cluster from scratch, provisioned with Terraform, configured with Ansible, deployed with GitOps, because understanding what happens under the hood makes you a better engineer.

🔗 [View Repository](https://github.com/Fella-ould-aek/imgapp-gitops-helm)
